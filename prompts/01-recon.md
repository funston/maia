# 01 - Repo reconnaissance

**When:** First thing after opening the repository. Budget: 5 minutes.

```text
I'm working in an unfamiliar codebase under a time limit. Inspect the
repository without modifying anything.

Report:
1. Language, framework, build system, and test runner.
2. The main components and entry points, with file paths.
3. Any README, CLAUDE.md, AGENTS.md, CONTRIBUTING, or task/issue files, and
   what they ask for.
4. The exact command to run the test suite, and to run a single test.
5. Conventions I should follow for tests and error handling.

Keep it to a short map I can read in one minute. Do not install anything or
run the full test suite yet. If something is unclear, say so rather than
guessing.
```
