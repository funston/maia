# 02 - Root-cause investigation

**When:** After recon, before any edit. Budget: 7 minutes.

```text
Investigate this issue. Do not modify any code yet.

[PASTE ISSUE TEXT]

Trace the execution path from the public entry point to the faulty
behaviour, then report:
1. The functions and files involved, in call order.
2. Expected versus actual behaviour.
3. The most likely root cause, quoting the lines that support it.
4. Whether that cause explains every symptom in the issue. List any
   symptom it does not explain.
5. Alternative hypotheses worth ruling out.
6. The smallest test that would reproduce the failure.

Mark each statement as observed in the code or as a hypothesis. No
refactoring suggestions.
```
