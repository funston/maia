# 11 - Feature plan before implementation

**When:** The task is to add behaviour rather than fix a bug.

```text
I need to add this feature:

[PASTE FEATURE REQUEST]

Do not write code yet. Give me a plan:
1. The existing code this touches, and the extension point that fits best.
2. The interface: signatures, config, defaults, and what stays backward
   compatible.
3. Edge cases and invalid inputs, and how each is handled.
4. The tests you would write first.
5. The smallest slice that delivers working, tested behaviour, and what you
   would defer.
6. Open questions I should answer or ask the interviewer.

Keep it to what fits in [N] minutes of implementation.
```
